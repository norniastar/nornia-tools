## 线上

- CrUX：PageSpeed Insights API 没有返回数据（流量小的站常见），如实记为「没有」。
- 直接量：`tools.nornia.top` TTFB 0.256s，同时段对照站 vercel.com 0.226s，差不多，首字节不是瓶颈。
- 线上静态资源经 Cloudflare 走 br 压缩，`cache-control: max-age=14400`，`cf-cache-status: MISS`。

## 首屏拆解

- 构建产物只有一个 JS：`index-*.js` 2,412 KB（gzip 674 KB），外加一个 CSS 74 KB（gzip 13 KB）。
- 所有工具（含 jsoneditor/Ace、yaml、lossless-json、motion、DateTimePicker 等）都打进了这一个包，无论打开哪个页面都要先下载、解析整包。在 fast4g 下光这一个文件就要约 1.4s。
- 文本代码对比页：`@monaco-editor/react` 默认从 `cdn.jsdelivr.net` 拉 Monaco（AMD loader + editor.main 等 11 个请求、约 1 MB），排在主包之后才开始，形成瀑布；能用 p75 5.7s。jsDelivr 在部分地区访问不稳定。
- Cloudflare Web Analytics beacon 是 `defer` 的外部脚本，不在关键路径上。
